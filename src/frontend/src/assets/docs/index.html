Kritik Verilerinizi Güvenle Yönetin

Secure Box, API anahtarları, şifreler, sertifikalar ve hassas bilgilerin şifrelenmiş olarak saklanmasını ve yönetilmesini sağlayan, kurumsal düzeyde bir güvenlik çözümüdür. 📋 Proje Hakkında

Secure Box, modern microservices mimarisine dayanan, ölçeklenebilir ve yüksek erişilebilirlik özelliklerine sahip bir güvenlik platformudur. Docker ve Kubernetes ile konteynerize edilmiş, load balancing ve monitoring çözümleri ile production-ready bir sistemdir.

✨ Temel Özellikler

🔐 Sertifika Tabanlı Şifreleme

X.509 sertifikaları kullanarak AES-256-GCM ve RSA ile çok katmanlı şifreleme. Tüm hassas veriler şifrelenmiş olarak saklanır.

🎫 JWT Authentication

Modern ve güvenli JWT tabanlı kimlik doğrulama. Access token (15 dk) ve refresh token (7 gün) ile oturum yönetimi.

👥 Rol Bazlı Erişim Kontrolü

Admin, Client ve Service rollerinin yanı sıra özelleştirilebilir roller ve detaylı izin yönetimi (RBAC).

📝 Kapsamlı Audit Logging

Her işlem kayıt altına alınır. PostgreSQL ve MongoDB üzerinde immutable audit trail. ELK Stack ile log analizi.

🔄 Anahtar Rotasyonu

Otomatik ve manuel key rotation desteği. Version kontrolü ile eski anahtarlara erişim ve geçmişi izleme.

📜 Sertifika Yaşam Döngüsü

Sertifika yükleme, geçerlilik kontrolü, süre dolumu bildirimleri ve iptal (revocation) yönetimi.

🌐 Modern Web Portal

Angular ile geliştirilmiş, responsive ve kullanıcı dostu admin paneli. Material Design bileşenleri.

🚀 High Availability

2+ API replica ile load balancing. Nginx reverse proxy, Redis cache ve RabbitMQ ile ölçeklenebilir altyapı.

📊 Monitoring & Analytics

ELK Stack (Elasticsearch, Logstash, Kibana) ile gerçek zamanlı log izleme ve analiz. Performans metrikleri.

🚀 Hızlı Başlangıç

# Projeyi klonlayın
cd secure-box

# Docker-Compose ile tüm servisleri başlatın
docker-compose up -d

# Servis durumlarını kontrol edin
docker-compose ps

# Logları izleyin
docker-compose logs -f

# Servisleri durdurun
docker-compose down
